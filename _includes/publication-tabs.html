{% comment %} Section switcher for the Publications pages. Each section is a real page of its own, so switching loads a fresh page at the top instead of swapping content in place. A category only gets a link once it has entries, so an empty one never shows an empty page. Styling lives in _sass/layout/_section-tabs.scss. Pass the active category, e.g.: {% include publication-tabs.html active="books" %} {% endcomment %} {% include base_path %} {% assign tab_categories = "manuscripts,books,conferences" | split: "," %}
{% for cat in tab_categories %} {% assign cat_posts = site.publications | where: "category", cat %} {% if cat_posts.size > 0 %} {% case cat %} {% when 'books' %} {% assign cat_url = '/publications/books/' %} {% when 'conferences' %} {% assign cat_url = '/publications/conferences/' %} {% else %} {% assign cat_url = '/publications/' %} {% endcase %} {{ site.publication_category[cat].title }} {% endif %} {% endfor %} {% comment %} Patents sit in the same switcher but are not part of the publications collection, so they get an unconditional link rather than a count. {% endcomment %} Patents
